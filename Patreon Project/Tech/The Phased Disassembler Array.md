# TECHNICAL SPECIFICATION SHEET: THE PHASED DISASSEMBLER ARRAY

Classification: Private. Industrial units built by Oyama Industries for the organization alone.
System Status: Active

## I. OVERVIEW

The Phased Disassembler Array is a machine that takes in scrap, vaporizes it, breaks the vapor down to its base elements, and sorts those elements by atomic mass. Nothing is wasted. Whatever goes in comes out as clean stock of its component elements, ready to use in manufacturing.

It exists in two builds.

- **The original unit.** Crude and slow. It breaks scrap down to base elements over a long time and was the first machine built to feed the others.
- **The industrial array.** Built by Oyama Industries. It takes in scrap by the ton and runs continuously.

## II. OPERATION

Scrap is loaded into the intake. A Dumb AI on a data crystal runs the cycle: it reads what the intake holds, sets the phase pattern for that material, and runs the array until the load is spent. Sorted elements leave through separate outlets, one per element, into storage.

An operator chooses what the array is fed and where each outlet runs. The array does the rest.

## III. FUNCTIONALITY

1. **Intake.** The array accepts metal, mixed scrap, trash, and anything else that would be paid to be hauled away. It does not need the load sorted beforehand.
2. **Disassembly.** The emitters phase the target matter to vapor and break it down to its base components.
3. **Separation.** The vapor passes through a separator that sorts each element by atomic mass.
4. **Output.** Each element leaves as clean stock. Nothing is left over as waste.
5. **Collection and assembly.** The array's stock feeds the organization's fabrication lines directly. Anything the organization builds, from structural plate to the contents of a Med-Pod's feedstock tank, comes from stock the arrays produced.

## IV. TECHNOLOGIES EMPLOYED

1. **Phase emitters.** A ring of emitters around an open chamber holds the target matter and drives it to vapor.
2. **Mass separator.** Sorts the vapor by atomic mass into its elements.
3. **Dumb AI.** A non-sentient controller runs each cycle. It reads the load, sets the phase pattern, and manages the separator. It makes no decision beyond the run.
4. **Data crystal.** Holds the controller and the run logs.
5. **Power.** The industrial array runs on a tokamak fusion reactor. The original unit ran on whatever power could be had and was slow because of it.
6. **Automated scrapper.** A machine built to roam and collect metal and bring it in. It feeds the original unit.

## V. PHASED DISASSEMBLY

1. **Vaporization.** The emitters raise the target matter past solid, liquid, and compound form until it is a vapor of free atoms.
2. **Breaking to base components.** Molecules and alloys come apart into their elements.
3. **Sorting by atomic mass.** Each element is pulled off the stream at its own stage.
4. **No waste.** Every atom that enters leaves as stock, so nothing needs to be dumped or treated.

## VI. LIMITS

- The array separates what the load contains. An element absent from the feed does not appear in the output.
- Throughput is set by the power available. A larger array runs more material for more power.
- It disassembles matter. It does not build anything.

## VII. SAFEGUARDS

- **Secrecy.** The array stays private. No unit is sold, and its design is never released.
- **Placement.** Industrial arrays stand on private sites only, guarded around the clock.
- **Supply.** Scrap is bought across the country, through shell companies, so the buying leaves no pattern pointing at any one buyer.
